# Data

`golden_dataset.json` and `policy_docs/` are copied **unchanged** from
[hr-policy-eval-harness](https://github.com/robertciceroson/hr-policy-eval-harness),
where the curation methodology is documented. Do not edit them here. Holding
them fixed is what makes the experiments comparable. To change the dataset,
change it in the harness repo and re-copy.
